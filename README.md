# 🕌 ZouAthan PRO para Enigma2

**ZouAthan PRO** es un plugin avanzado para decodificadores de televisión basados en **Enigma2** (OpenATV, OpenPLi, BlackHole, EGAMI, etc.). Muestra las horas exactas de las oraciones islámicas, permite escuchar el Athan, consultar la fecha en el calendario hégira (*Hijri*) y escuchar el Noble Corán directamente desde tu receptor.

---

## ✨ Características Principales

* ⏰ **Tiempos de Oración Precisos:** Cálculo de horarios mediante la API de Aladhan (*Fajr, Dhuhr, Asr, Maghrib, Isha*).
* 🌍 **Geolocalización Automática por IP:** Detecta tu país y ciudad automáticamente pulsando un botón.
* 📍 **Base de Datos Integrada:** Incluye ciudades predefinidas de España, Marruecos y Francia.
* 🔔 **Avisos y Notificaciones:** Cartel emergente en pantalla al llegar la hora de la oración.
* 🔊 **Reproducción del Athan:** Reproduce el aviso sonoro del Athan en segundo plano.
* 📖 **Noble Corán Integrado:** Escucha cualquier sura del Corán directamente en streaming.
* 🎨 **Interfaz Adaptada:** Skin flotante moderno compatible con pantallas Full HD.
